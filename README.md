# windows-to-android

A Windows 11-style Android launcher, distributed as a prebuilt APK.

## Download

[![Latest release](https://img.shields.io/github/v/release/ether4o4/windows-to-android?label=Latest%20APK&logo=android&color=3DDC84)](https://github.com/ether4o4/windows-to-android/releases/latest)

**[⬇ Download the latest APK](https://github.com/ether4o4/windows-to-android/releases/latest)**

Release assets are versioned (`NeverSoft11-v0.2.7.apk`), so the link above points at the latest
release *page* rather than a fixed filename — it keeps working as new versions ship. Grab the `.apk`
listed under Assets.

On the device, enable *Install unknown apps* for your browser, then open the downloaded file.

> To get a single fixed download URL that never changes, publish each build to a rolling
> `android-latest` tag under a constant filename (e.g. `neversoft11.apk`) alongside the versioned
> release.
